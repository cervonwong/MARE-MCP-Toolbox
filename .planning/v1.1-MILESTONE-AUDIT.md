## Current Test Gaps

### 1. Full suite red in current working tree

Command:

```text
cd mcp-gateway && uv run pytest -m 'not slow'
```

Result:

```text
8 failed, 586 passed, 48 skipped, 13 deselected
```

Failures:

- `tests/test_acl_available.py::test_setfacl_on_path`
- `tests/test_r2_sessions.py::test_unsafe_shares_combined_cap`
- all 6 tests in `tests/test_sessions_concurrency.py`

The ACL failure is host-environmental: `setfacl` is not installed on the host, while `Dockerfile` includes the `acl` package and re-applies ACLs at container start. The current test is intentionally fail-loud, but that means the host full suite is not green.

The Phase 13 failures are full-suite-order issues. Isolated runs pass:

```text
uv run pytest tests/test_sessions_concurrency.py -q
6 passed

uv run pytest tests/test_r2_sessions.py::test_unsafe_shares_combined_cap -q
1 passed
```

Minimal reproducer:

```text
uv run pytest \
  tests/test_gdb_session.py::test_gdb_env_validates_bad_values \
  tests/test_r2_sessions.py::test_unsafe_shares_combined_cap \
  tests/test_sessions_concurrency.py -q

7 failed, 1 passed
```

Root-cause evidence:

- `src/mcp_gateway/tools/r2_sessions.py` warns that `from X import Y` bindings do not survive `importlib.reload`, but still imports `SessionCapReached` by value and catches that stale class. After `mcp_gateway.sessions._base` is reloaded, the raised `SessionCapReached` is a new class object and escapes the `except`.
- `src/mcp_gateway/sessions/__init__.py` reloads submodules but does not guarantee `mcp_gateway.sessions.r2` remains a package attribute after tests pop/re-import the package. `monkeypatch.setattr("mcp_gateway.sessions.r2._open_r2", ...)` then fails.

## Recommended Closure Order

1. Fix the Phase 13 full-suite-order failures:
   - make `tools/r2_sessions.py` catch `sessions.SessionCapReached` by module attribute, not a stale imported class;
   - ensure `mcp_gateway.sessions.__init__` exposes `r2` and `gdb` package attributes after reload/re-import, or adjust tests to import modules directly.
2. Decide the host contract for `test_acl_available.py`: either run it only in the container or install/require `acl` on the host. Do not leave it as an unconditional host full-suite failure.
3. Add Phase 13 requirements to `REQUIREMENTS.md` and traceability, or explicitly mark Phase 13 as a post-v1.1 closure phase outside the milestone.
4. Run and record the 15 pending container/live-client UAT checks.
5. Normalize `.planning` state: ROADMAP checkboxes/progress, stale requirement checkboxes, traceability `Verified` values, and VALIDATION.md frontmatter.

## Final Assessment

v1.1 is code-complete in the narrow sense that all declared features and hardening items have implementation evidence. It is not milestone-complete yet. The archive gate should stay closed until the full suite is green under the intended host/container contract, Phase 13 is traceable, and the pending runtime UAT is recorded.
