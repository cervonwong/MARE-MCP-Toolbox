1. **D-01:** `tools/r2_sessions.py` currently imports `SessionCapReached` by value (`from mcp_gateway.sessions import SessionCapReached`). After `importlib.reload(mcp_gateway.sessions._base)` runs (triggered by `test_gdb_env_validates_bad_values`), the raised `SessionCapReached` becomes a new class object and escapes the `except` binding. Fix: catch via module attribute (`sessions.SessionCapReached`) so the class is resolved at exception-catch time and survives reload.

After the gdb-env reload cleanup path, `monkeypatch.setattr("mcp_gateway.sessions.r2._open_r2", ...)` fails because `mcp_gateway.sessions.r2` is no longer a package attribute. Fix: re-bind `r2` and `gdb` as package attributes from `sys.modules` at the end of `__init__.py` so the bindings always exist after package load.

3. **D-04:** `tests/test_acl_available.py::test_setfacl_on_path` fails loudly on hosts that lack `setfacl`. Phase 14 D-04 picked **Option A** — mark container-only via `@pytest.mark.skipif(shutil.which('setfacl') is None, reason="setfacl host-binary missing; container-only contract")`. Add a module docstring explaining the contract.
